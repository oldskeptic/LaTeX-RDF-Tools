\section*{RDFTools glossary example}
% Compact and two-argument references can be mixed in the same document.
A \RDFTermName{vocab:Report} is defined as:
\RDFTermDefinition{vocab}{Report}

Its immediate superclass is \RDFListSuper{vocab}{Report}.
Its superclass hierarchy is \RDFListSuperTransitive{vocab:Report}.

The resource identifier is \RDFTermURI{vocab:Report}.

The ownership relation is \RDFTermName{vocab}{owns}.
